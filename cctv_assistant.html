1. Information Collection and Use

CCTV Assistant operates as a local utility tool to monitor and manage user-configured security streams. The application does not collect, harvest, store, or share any personal, identifiable, or usage information. All configurations and video stream data remain strictly local to your physical Android device.

2. Network and Overlay Operations (Tor & I2P)

To secure data exchange this application utilizes decentralized routing networks, specifically Tor and the Invisible Internet Project (I2P) protocols. No Data Traffic Logging: The application does not log, inspect, or intercept the contents of any network package passing through these encryption layers. Third-Party Disclosures: No telemetry or routing metadata is shared with any external servers or third-party entities. 3. System Permissions Required Battery Optimization Bypass (REQUEST_IGNORE_BATTERY_OPTIMIZATIONS): Required to ensure background persistent connection stability for vital security streams and network nodes when the device screen is off.
